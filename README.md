# 🌱 Planeta Vivo – Pequenas Ações, Grande Planeta

Landing page (página única) sobre **Sustentabilidade no Dia a Dia**, tema da **Agenda 2030** da ONU.

O site mostra como atitudes simples, como reciclar, economizar água e consumir com consciência, ajudam o planeta e contribuem para os Objetivos de Desenvolvimento Sustentável (ODS).

## 🔗 Site publicado

> Troque pelo seu link: `(https://ysmgtz1996.github.io/planeta-vivo/)`

## 🛠️ Tecnologias usadas

- HTML5
- CSS3
- Bootstrap 5.3 (via CDN)
- Bootstrap Icons
- JavaScript (validação do formulário)
- GitHub Pages (publicação)

## 🧩 Componentes do Bootstrap utilizados

| Componente | Onde aparece |
|---|---|
| Navbar | Menu fixo no topo, que vira "hambúrguer" no celular |
| Carousel | Seção "Por que isso importa?" |
| Cards | Seção "Dicas para o dia a dia" |
| Accordion | Seção "Dúvidas frequentes" |
| Form | Formulário de cadastro, com validação |
| Alert | Mensagem de sucesso após o cadastro |

## 📱 Responsividade

A página usa o **sistema de grid do Bootstrap** (`row`, `col-12`, `col-md-6`, `col-lg-4`). Os cards ficam em 3 colunas no computador, 2 no tablet e 1 no celular.

## 📝 Formulário de cadastro

Pede nome, e-mail, tema de interesse e um aceite. O JavaScript valida os campos e mostra uma mensagem de sucesso. Os dados não são enviados para nenhum servidor (é só demonstração).
